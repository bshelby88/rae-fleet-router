# Endpoint Assurance Sprint

Static source for the public Endpoint Assurance offer and its educational field guide.

- Live offer: <https://bshelby88.github.io/rae-endpoint-assurance/>
- Field guide: <https://bshelby88.github.io/rae-endpoint-assurance/field-guide/>
- Fit-check request: <https://bshelby88.github.io/rae-endpoint-assurance/request-fit-check/>
- Pages source: repository root on `main`

The site contains no JavaScript, analytics, cookies, checkout, backend, credentials, or customer data. The fit-check page is a static checklist that opens the visitor's email client; it is not an intake system. The JSON example is explicitly synthetic and uses reserved documentation domains and addresses.

The tested Endpoint Assurance evidence/state harness is the operational source for engagement state and immutable evidence. Airtable is a routing and visibility view only. Commercial revenue is recognized only through an independently reconciled ledger after unrelated third-party settlement, delivery, customer acceptance, and verification correlate.
