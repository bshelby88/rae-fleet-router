Field guide

Public endpoint evidence, without the guesswork.

A bounded observation records what an external client saw during a defined window. It does not automatically establish root cause, uptime, security, compliance, or customer impact.

Synthetic demonstration. The sample on this page is fictional and illustrative. It is not a customer engagement, testimonial, production incident, independent verification, or proof of results.

What to record

DNS
Resolved record type, returned documentation address, resolver context, UTC timestamp, and limitations.
TLS
Presented hostname, issuer, validity window, certificate fingerprint placeholder, and protocol observation.
Redirects
Each public hop, status, destination, and whether the final URL matches the expected customer path.
HTTP
Status, bounded latency sample, selected safe headers, and a sanitized response-content hash.
Customer path
Whether the agreed public pages agree with one another. A homepage 200 does not prove that documentation, authentication, checkout, or webhooks work.

Observation is not inference

Observed: During the synthetic UTC sample window, the fictional documentation URL returned a redirect to the canonical HTTPS path and then a 200 response.

Inference: Not determined. One successful response does not establish availability, correctness, security, or the health of other customer paths.

Recommendation: Repeat the same bounded observation from an independently controlled environment and compare the immutable evidence records before deciding whether remediation is needed.

Reproducibility checklist

  • Record UTC timestamps, observer identity class, method, and tool version.
  • Normalize the target and reject private, local, reserved-network destinations during real checks.
  • Revalidate every redirect and preserve the ordered redirect chain.
  • Hash sanitized evidence artifacts and keep observations append-only.
  • Separate observation, inference, recommendation, and untested hypothesis.
  • Use independent verification before calling a remediation complete.

Boundaries

This method is not penetration testing, vulnerability assessment, certification, compliance assurance, continuous uptime monitoring, or proof of root cause. It uses only customer-authorized public targets. Private systems, credentials, invasive testing, and production implementation are excluded.
